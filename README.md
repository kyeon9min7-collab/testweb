# 포켓몬GO IV 계산기

포켓몬GO에서 잡은 포켓몬의 CP·HP와 팀 리더 감정 결과를 입력하면, 가능한 개체값(IV) 조합을 계산해서 100%(헌드로) 여부를 판별해주는 한국어 웹앱입니다.

빌드 없이 정적 파일만으로 동작합니다. `index.html`을 열거나 아무 정적 파일 서버로 서빙하면 됩니다.

```
python3 -m http.server 8000
# http://localhost:8000 접속
```

아이폰/안드로이드 모두 Safari/Chrome에서 열어 "홈 화면에 추가"하면 앱처럼 바로 켜서 쓸 수 있습니다.

## 사용법

1. 포켓몬 이름(한글/영문/도감번호)으로 검색해 선택합니다.
2. 포켓몬 정보 화면에 표시된 CP, HP를 입력합니다. (선택) 내 트레이너 레벨과 버디 상태를 입력하면 가능한 레벨 범위가 좁혀져 결과가 더 정확해집니다.
3. "IV 계산하기"를 누르면 CP/HP에 부합하는 모든 (레벨, 공격/방어/체력 IV) 조합을 보여주고 100% 가능성을 판정합니다.
4. 게임 내 "감정하기" 결과(능력치 막대 색)를 그대로 선택하면 조합이 더 좁혀져, 대부분의 경우 정확히 하나로 확정됩니다.

## 파일 구성

- `index.html` — 페이지 구조
- `style.css` — 스타일 (라이트/다크 모드 대응)
- `data.js` — 포켓몬 종족값(공격/방어/체력) + 레벨별 CPM(전투력 배율) 데이터
- `app.js` — IV 조합 계산 로직 및 UI 동작

## 데이터 출처

- 종족값(base stats): [PvPoke](https://pvpoke.com) 커뮤니티 게임마스터 데이터
- CPM(레벨별 전투력 배율): 나이언틱 공식 게임 마스터 데이터([PokeMiners/game_masters](https://github.com/PokeMiners/game_masters) 미러 기준). 레벨 1~40 범위를 지원하며, 이는 야생/레이드/알부화로 얻는 포켓몬의 사실상 모든 레벨을 포함합니다.
- 한글 이름: [PokeAPI](https://pokeapi.co) 다국어 이름 데이터
